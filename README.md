# To-Do List App

A command-line task manager that lets you add, view, and remove tasks, with persistent storage using file handling.

## Features
- Add new tasks
- View all current tasks
- Remove completed tasks
- Tasks are saved to a text file, so they persist even after closing the program

## Tech Stack
- Python (no external libraries required)

## How to Run
```bash
python todo_list_app.py
```

## What I Learned
- File handling in Python (reading and writing to a text file)
- Building a simple menu-driven CLI application
- Basic error handling for invalid user input

## Example
```
1. View tasks
2. Add task
3. Remove task
4. Exit
Choose an option (1-4): 2
Enter the new task: Finish resume
Added: Finish resume
```
